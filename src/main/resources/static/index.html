失业后，养老怎么接着交？

原来是职工养老

符合条件时，可用灵活就业身份继续参加企业职工养老保险，已有年限和账户接续；它不是商业“个人养老金”，也不是自动改成居民养老。参保地、就业登记和资格需按广东规定办理，可通过粤税通或税务窗口查询申请。

中途断缴了

原来的缴费月数和账户不会清零。暂停期间不增长缴费年限，灵活就业通常不得补缴漏交年份，政策例外需经办确认。

到退休年龄，还没交够

最低年限按退休年份判断，2030年起逐步从15年增至20年。测算会模拟继续缴费并延后领取；不自动假设能一次性补齐。

领取失业保险金的人

符合领取失业保险金且距法定退休年龄不足一年等条件的人员，可能由失业保险基金按规定缴纳养老保险；本工具暂不扣除这项代缴，也不自动计算补贴，申请前可咨询020-12333。

假设与政策来源

保持缴费和计发基数不变，未来利息按0，未知历史指数按0.6。退休总额包含以前已有权益；用总额收回续交费用，不能视为续交投资回报。未计算通胀、资金时间价值、养老金调整、医保和补贴。
