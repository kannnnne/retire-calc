# 简易预测（2026-10-08重做）

首页为普通职工的恒定价格预测。旧静态核算文档仍说明 /api/calculate；本文件描述新增 /api/forecast，若旧文档出现“未来预测未实现”，以本文件为准。

输入与缺省：本金必须填，另填已累计利息，避免重复计入；当前基数留空按5510；历史指数留空按0.6。不读取个人账号、不反推官方历史指数。未来缴费基数5510引用粤人社发〔2025〕32号广州下限（2025-07起），未来最低档可能变化。计发基数沿用已录入最新官方参数9493，未来利息0。

核验原文：https://www.zhanjiang.gov.cn/zjsfw/bmdh/rsj/zwgk/zdlyxx/jyxxgk/zczy/content/mpost_2121540.html 。2026缴费通知搜索有线索但原文未能访问，因此没有标为2026已核验参数。

算法：从权益截至次月至法定退休月（包含退休月）模拟连续缴费；继续当前/最低档持续缴费不足最低年限时延缴。最低档交够即停缴的未来月数为 max(0,法定退休年份最低月数−已交月数)。资格月为 max(法定退休月,最后缴费月)，预计次月领取；延缴资格需社保确认，不自动承诺补缴或一次性缴费。

综合指数 =（历史指数×已缴月数＋未来假设指数×未来月数）÷总月数。未来假设指数=0.6×未来基数÷5510；这是情景代理，非对应年度官方工资指数。退休账户=本金＋已累计利息＋未来基数×8%×未来月数。基础养老金沿用广东公式。个人账户养老金按领取整岁官方计发月数；非整岁给出相邻整岁两种代入值的区间，不将区间宣传为实际待遇保证。

停止缴费只是比较，不代表单位在职职工可以免缴。未包含特殊历史待遇。1998年7月前首次参保拒绝简易预测；历史静态API仍保留。女性类别需按人事或社保认定选择。

界面：输入明显，说明默认折叠，三方案同时比较，主结果显示预计领取月份。教程用用户给的四张脱敏截图，当前缴费基数明细页未提供，不虚构截图。

虚构测试例手算：349个未来月，本金95000.00 + 5510×0.08×349 =248839.20；470个月，基础9493×0.8×470÷12×0.01=2974.4733；账户÷117=2126.8308，合计5101.30。最低年限20年，补119个月；账户147455.20，基础1518.88，账户1260.3009，合计2779.18。

## 2026-10-09续交与费用模型

请求新增 contributionType=FLEXIBLE/EMPLOYEE（省略默认FLEXIBLE）、pauseMonths（默认0）、customMonths（默认60）、plan新增CUSTOM。灵活就业法规粤人社规〔2026〕14号已核验，2026-05-01起有效2年；未来假设该比例延续，不标为未来必然政策。

未来付款率=20%（个人续交）或8%（单位本人）。每月个人付款=基数×付款率，后续费用=每月付款×未来实际缴费月数；未来账户增量始终=基数×8%×未来月数，统筹部分不加到账户。若无需未来缴费，每月未来付款返回0。

暂停从截至次月开始，不计月数；续交开始月=截至月+暂停月数+1。退休前可交月数=max(0,截至到退休整月差−暂停月数)。常规持续方案补足法定退休年份最低门槛；交够即停方案只补差额。CUSTOM采用当前/自选基数与指定月数；不够门槛返回qualified=false、shortMonths、费用，但总养老金/领取月份/回收期为null。

费用回收月数=ceil(后续费用÷养老金总额)，区间分别用高/低月金额计算。起点是领取开始月，不是付款开始月；未计已有缴费成本、利息机会成本、等待时间、领取期养老金调整、死亡/继承、医保及补贴。它含已有权益，不是新增缴费收益率。

新增待遇对照只在已有月数≥最低门槛时提供，保持相同领取年龄、参数与历史权益，计算基础养老金增量＋未来账户增量÷计发月数；费用÷新增待遇。已有年限不足时不提供虚构可领取的“不续交养老金”对照。

界面以3步表单与独立结果页为主，默认无个人资料。显式按钮可填虚构5年续交示例；旧个人余额图片和示例金额不再用于界面。可查四步粤省事教程，余额已打码。

Windows使用jpackage app-image，启动参数--desktop。DesktopLauncher启动127.0.0.1随机端口、显示小型控制窗口、自动打开系统浏览器；关闭窗口关闭Spring上下文。运行时内置，不依赖系统JAVA_HOME。EXE的引导进程会再启一个同名子进程，测试端口需查实际子进程。
