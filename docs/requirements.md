# 产品需求 / MVP

## 用户与边界

面向广州企业职工养老保险普通参保人及财务测算人员。默认法定退休，女性退休类别需按人事/社保认定选择；不根据性别或灵活就业自动推断。第一版静态权益计算，不推算未来缴费、账户利息、指数增长，也不把未达缴费要求的分项金额宣传为可领取待遇。

## 输入

- 出生年月、男/原55岁女/原50岁女类别、首次参保年月。
- 权益记录截至年月、当前累计**实际**缴费月数、当前个人账户余额。平均指数支持“已知 / 暂时不知道”，不知道仍能计算退休日期和缴费要求，基础与总额待补充。已知指数使用含视同的全程口径；与可选视同月数相加，明确防止重复计算。
- 历史权益三态：无/有且已核定/不知道。1998-06以前参保自动提示历史权益；视同月数、1998前实际月数、历史平均指数/视同指数按分支填写。未知阻断总额。
- 基数模式：最新正式录入年度（演示）或用户假设。不要输入身份证、姓名、手机号。

## 输出与状态

法定退休年月、精确年龄、距退休月数、弹性提前理论下界、当月审核通过假设下领取次月。当前累计缴费与法定退休年最低要求比较、差额月数。达标只指缴费条件，不表述为现在可领取。未退休显示未来累计缴费/账户预测未启用。

金额：基础、个人账户、过渡性；任何分项未知则合计为空并突出原因。缴费不足仍可显示参考分项，但标记“未满足缴费条件，不可作为可领取待遇”。数据过期/改表后旧结果隐藏，避免错配。

完整过程、输入快照、基数年份、参数版本、每项政策链接、生效时间与适用状态可展开。金额有明确静态标签与非核定提示。错误定位字段，支持键盘和窄屏、请求中防重复、后端校验、不保存个人权益数据、不记录请求正文。

## 页面

采用米白纸张和深绿的财务手册风格，左侧录入、右侧退休时间及金额卡；醒目的数据截至日期与演示标记。历史权益放在展开区。空白结果先说明所需数据；提供具名“示例数据”按钮，不能伪装成用户真实数据。

提供可展开的广州数据查询指南，字段下有官方入口，解释指数、月数、余额口径和查不到时的咨询方式。政策年度参数由系统默认选择，政策核验由维护者承担，不让普通用户确认政策。详见data-guide.md。

## 验收

三类延迟退休、2030—2039缴费增长、0.6边界、过渡性两分支、未知历史/非整数年龄/缺年度参数均正确。API拒绝未来出生、参保早于出生、累计实际月数超过参保至截至月可用月份、负金额、非整数月份及MVP范围外退休年月；缺参保历史指数不得输出完整总额。官方案例复算、HTTP测试、页面桌面及手机验证。

## 第二阶段

未来缴费和利息预测、历年缴费记录导入与指数合成、三档模拟、累计领取、报告/Excel导出。实施前补齐年度历史工资参数与适用口径，并分别展示事实/预测及假设。
