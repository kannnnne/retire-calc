# 广州用户数据获取指南

核验：2026-10-08。渠道可能调整菜单，必须由本人在官方平台登录和实名认证。计算器不与社保账户连通，不代登录，不采集密码。

## 官方入口

1. [广东社保服务](https://hrss.gd.gov.cn/gdsbfw/) → 社会保险网上个人服务 → 个人权益记录（参保证明）查询打印 / 社会保险参保缴费记录查询。入口现仍可访问，省人社页面提供个人网厅链接及咨询电话020-12333。
2. 微信“粤省事”：办事城市选广州 → 社保·就业 → 养老 → 个人权益缴费记录查询（养老保险） → 职工社保，按查询年份查看。[2026年省内平台操作图解（江门社保局发布）](https://www.jiangmen.gov.cn/bmpd/jmsshbxjjglj/zwgk/sbdt/content/post_3452581.html)。图解的服务平台可供广州用户参考，但不承诺登录后各城市菜单、字段完全一致。
3. 广东人社APP：公共服务 / 社会保险 / 个人权益单；粤省事另有社保凭证 / 个人权益单打印。[广州人社官方渠道说明](https://rsj.gz.gov.cn/zmhd/cjwt/content/post_8310889.html)，发布2022年，菜单以当前界面为准。
4. [广州经办机构名单入口](https://rsj.gz.gov.cn/zwdt/gzdt/content/post_10191478.html)：官方通告附件4列有各区、街镇经办和退管大厅名单，名单发布2025年；先电话确认是否办理所需查询业务，不将资格认证银行网点直接推荐为指数核定机构。

## 字段怎么找

| 输入 | 获取 / 核对 |
|---|---|
| 出生年月 | 社保认定的出生信息，档案与身份证冲突时不能让计算器自行判定 |
| 原法定退休类别 | 女性50/55类别向单位人事或社保经办核对；不是按职位名自动判定 |
| 首次参保 | 养老保险参保信息及最早参保记录，不取医保时间 |
| 实际累计月数 | 优先已核定累计实际月数；逐月记录只数缴费月，断缴不计，重复月份不累加。含视同的累计年限先减掉另填的视同，避免双算 |
| 账户余额 | 养老个人账户含利息累计储存额，不是医保账户、银行卡金额、全部社保缴费合计。页面只有本金或口径不明时咨询经办机构 |
| 权益截至年月 | 记录统计截至月份；不机械等同于打印日期 |
| 平均指数 | 已显示/已核定的本人全程平均缴费指数（含视同）；普通参保证明不保证显示该字段 |
| 历史权益 | 视同月数、历史实际月数、历史指数来自经办核定；工作与参保间隔不能自行认定为视同 |
| 年度基数 | 系统自动选录入参数，普通用户不用查询确认；假设模式用于主动做敏感性测算 |

## 平均缴费指数

反映历月相对缴费水平，并按缴费月份汇总；视同缴费适用核定指数等规则。不能用当前工资、当前缴费档次、账户余额除以总缴费额代替。算法依据粤府〔2006〕96号及后续政策，详见pension-policy。

有完整历月记录、相应官方比较基准与历史口径时，可由程序合成；本版仍不提供历年记录导入/自动合成。也不能从几个汇总金额反推出全程指数。普通参保证明不一定有该字段，本次未登录个人账号验证，不宣称平均指数一定可在线直接查到。

页面默认“暂时不知道”：平均指数可为null，基础养老金PENDING、总额null，但退休日期、缴费条件和已知账户分项仍能算；补充正确指数后重新提交。不用示例0.6或1.0替用户猜填。

向020-12333或经办机构可问：“我想测算企业职工养老金，如何查询累计实际缴费月数、个人账户含利息储存额，以及本人平均缴费指数（含视同）？如果尚未核定，需要提供什么材料？”
