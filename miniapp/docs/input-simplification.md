# 输入简化与2026缴费参数核验

2026-10-09。本轮修改原生小程序，尚未上传、提交代码审核或发布。

第一页默认连续缴费：截至月减首缴月加1。首尾均假设已缴费。2016-07至2026-09是123个月，扣除2个月断缴后121个月。可切换停交扣除、按查询记录填写；修改日期自动更新计算值，手填记录模式保留记录月数。跨度不证明实缴到账，有欠费、跨地记录或补缴时以查询为准。

个人账户本金必须查，不默认0或用现行最低档倒推历年。历史最低基数逐年不同，不能将当前最低基数×8%×月数当作已积累金额。若用户有完整逐月历史缴费及利息记录可另做累加，但本版不提供该数据模型。

续缴默认最低档情景，保留单位在职默认身份与当前基数交到退休方案。四种基数来源：最低档、单月在职养老保险个人扣款÷8%、税前月工资估算、已知缴费基数。反推不能使用社保总额、医保、公积金、单位费用、补缴或多月扣款。工资优先上一年度税前月平均收入，含奖金等，不保证等于实际申报基数；上下限夹取只应用于工资情景，扣款反推越界直接提示。最低档不替代单位如实申报义务。灵活就业可在规定上下限内选择基数。

核验发现新通知：粤人社发〔2026〕24号，发文2026-09-17，税务页面2026-10-08公开。企业职工2026年1月起统一下限5510元，2026年7月起下限5521元、上限27603元。按权益截至月份选取已录入缴费范围，未来维持该参数作情景估算。计发基数仍9493元（2025），未将缴费基数与养老金计发基数混用。历史指数未知仍0.6；未来指数代理仍0.6×所选基数/5510，为旧模型近似而非核定值。
