# 全国居民养老目标

## 范围与路线

2026-10-21用户授权持续目标：中国大陆31省级行政区及下属城市，只扩居民养老；港澳台制度不同暂不纳入。公共计算引擎→省级配置→必要本地覆盖。普通计算先可用，补缴按省级允许的漏年、提档、到龄补足逐类接入，不自动认定人人60岁可补。未知市县加发标明省级参考，不逐县无限查证。

省份的一条规则必须复用于其城市；已有杭州、西安、成都和两广地方例外保留。职工及灵活就业独立保留原40城，不随居民地区注册误开放。每个问题最多两条有效官方检索路径，保留缺项避免反复找同一资料。
