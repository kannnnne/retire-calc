# 居民缴费时间选择

## 2.7.0 已核云浮

[云府〔2026〕11号原文](https://www.yunfu.gov.cn/yfczj/gkmlpt/content/2/2042/post_2042086.html)第二项（三）：缴费满15年并继续缴费，从第16年起缴费补贴额外增加50元；第三项（二）：累计超过15年，每增加1年月基础待遇增加5元。有效期至2031-03-24，未来计算沿用当前规则，不承诺政策不变。

以前普通引擎仅安排交足15年；现在云浮可选：

- `payUntil=MINIMUM`：交够15年就停，默认及旧会话无此字段时保持原计划。
- `payUntil=SIXTY`：交够后继续正常年缴至60岁前。只在交足15年后仍有至少一个可正常缴费年度时显示，填表及结果“换个交法看看”中都能选择。不将该选择套给其他未核城市，不延长到60岁以后。

`resident/utils/payment-options.js`供表单和引擎计算可用年度；以现有年度计划的缴费月份安排，未来采用截至月份（有地方明确月份则用地方月份），生日边界按月份比较，60岁当月不再添加这条续缴计划的正常缴费。领取当年能否另缴、实际征缴月份须向经办核对，不宣称是当地实际扣费日。

配置项`continueTo60`控制已核地区开放；`postMinimumSubsidy`控制累计满15年后正常年度的额外补贴，云浮为50。其他城市可以核实后独立配置，不能仅因同省或已有READY而自动开启。云浮过去年限、金额不变；额外补贴只入账户，正常费用仍由本人承担，不把补贴扣减为本人少交；不补发过去年份的补贴，不任意提档已缴年度。

## 固定参数验算

截至2026-10、出生1971-10，已缴15年且包含今年，账户查询30000元，每年360元：

| 项目 | 交足后停止 | 继续到60岁前 |
| --- | --- | --- |
| 新增年缴 | 0年 | 2027—2030共4年 |
| 本人以后共交 | 0元 | 1440元 |
| 新增补贴 | 0元 | 4×(30+50)=320元 |
| 预计个人账户 | 30000元 | 31760元 |
| 基础部分 | 240元 | 240+4×5=260元 |
| 月待遇未取整 | 455.83元 | 488.49元 |
| 首次领取年份 | 2031 | 2031 |

金额未计未来利息和政策调整；界面仍按十元取整并加“约”。如果已缴14年、未来正常缴4年，则第15年只补30元，其后3年各补80元，共270元，不提前多发50。余额改为按过去缴费估算时，旧本金仍按旧年档乘年数，不重新套未来档。

## 2.7.1 江门

[江门市社保局2025年5月20日说明](https://www.jiangmen.gov.cn/jmshbj/gkmlpt/content/3/3301/post_3301142.html)明确，15年是最低年限，交够后可继续缴费，超过15年每多1年月加发不少于3元。按本市3元下限及现有九档补贴计算，未计未核县区额外提高。已缴年度调档次年生效；此功能只调整以后正常年缴，不重算已交金额，不把2025批扣提醒作为2026截止日。

江门设置continueTo60=true，postMinimumSubsidy保持未配置，不享云浮第16年额外50元。沿用相同的60岁前年月边界、默认MINIMUM、会话和换市规则。出生1971-10、截至2026-10、已交15年含今年、余额30000：360元年档继续4年，费用1440、补贴120、账户31560、基础254.50、月额481.55元（界面约480）；600档费用2400、补贴240、账户32640、基础254.50、月额489.32（界面约490）。不会把未来档次作用于原余额。

## 2.7.10 广西居民继续年缴与补缴年限联动（2026-10-19）

依据实际读取的自治区人社厅原文 http://rst.gxzf.gov.cn/zwgk/xxgkzcfg/xxgkgfxwj/t3247426.shtml （桂人社规〔2018〕22号，2018-10-31，官网标有效）第二部分（三）（四），普通15档200—6000元、35—200元补贴，鼓励早参保多缴费、超过15年每年加2元，并允许地方提高；2026-01-05自治区社保中心问答 http://rst.gxzf.gov.cn/jlhd/jlhdcjwt/shbz/t27083622.shtml 仍采用这些档次、补贴和长缴规则。后者现改为直接原站来源，替换原先可能打不开的政府总门户链接。

广西14市普通参保范围现可选交足15年后停，或在仍有额外年度时继续正常年缴至60岁前。该选项是依据长缴激励及普通年缴范围实现的比较，不是原文逐字写有一个名为“续缴到60”的产品；不从长缴条款推出60岁后自愿加缴、未满年限任意补足或过渡补缴资格。默认仍MINIMUM。自治区金额仍明确参考，南宁兴宁／青秀、玉林等本地加额保留；无云浮第16年另补50元。不重算历史本金或补发历史补贴。

补缴联动：ordinary-calculate原本会按有效补断缴增加年限计算，表单却只看原缴年数。payment-options.preview在存在广西补缴行时复用普通引擎按MINIMUM完整校验（含尚未领取、可补起点、年度合法性／重复、原记录和账户模式），拿有效addedYears判断是否有额外续缴年度；不只数行跨度。提档不增加年限。未核对、重叠、无效行不开放该选择；原计算报错仍保留。编辑、删除、换记录重做资格及可选方案判断。沿现有紧凑下拉框，不新增字段，页面风格不改；参考ui-ux-pro-max表单反馈与可见标签指南，未GUI操作。
