# 居民缴费时间选择

## 2.7.0 已核云浮

[云府〔2026〕11号原文](https://www.yunfu.gov.cn/yfczj/gkmlpt/content/2/2042/post_2042086.html)第二项（三）：缴费满15年并继续缴费，从第16年起缴费补贴额外增加50元；第三项（二）：累计超过15年，每增加1年月基础待遇增加5元。有效期至2031-03-24，未来计算沿用当前规则，不承诺政策不变。

以前普通引擎仅安排交足15年；现在云浮可选：

- `payUntil=MINIMUM`：交够15年就停，默认及旧会话无此字段时保持原计划。
- `payUntil=SIXTY`：交够后继续正常年缴至60岁前。只在交足15年后仍有至少一个可正常缴费年度时显示，填表及结果“换个交法看看”中都能选择。不将该选择套给其他未核城市，不延长到60岁以后。

`resident/utils/payment-options.js`供表单和引擎计算可用年度；以现有年度计划的缴费月份安排，未来采用截至月份（有地方明确月份则用地方月份），生日边界按月份比较，60岁当月不再添加这条续缴计划的正常缴费。领取当年能否另缴、实际征缴月份须向经办核对，不宣称是当地实际扣费日。

配置项`continueTo60`控制已核地区开放；`postMinimumSubsidy`控制累计满15年后正常年度的额外补贴，云浮为50。其他城市可以核实后独立配置，不能仅因同省或已有READY而自动开启。云浮过去年限、金额不变；额外补贴只入账户，正常费用仍由本人承担，不把补贴扣减为本人少交；不补发过去年份的补贴，不任意提档已缴年度。

## 固定参数验算

截至2026-10、出生1971-10，已缴15年且包含今年，账户查询30000元，每年360元：

| 项目 | 交足后停止 | 继续到60岁前 |
| --- | --- | --- |
| 新增年缴 | 0年 | 2027—2030共4年 |
| 本人以后共交 | 0元 | 1440元 |
| 新增补贴 | 0元 | 4×(30+50)=320元 |
| 预计个人账户 | 30000元 | 31760元 |
| 基础部分 | 240元 | 240+4×5=260元 |
| 月待遇未取整 | 455.83元 | 488.49元 |
| 首次领取年份 | 2031 | 2031 |

金额未计未来利息和政策调整；界面仍按十元取整并加“约”。如果已缴14年、未来正常缴4年，则第15年只补30元，其后3年各补80元，共270元，不提前多发50。余额改为按过去缴费估算时，旧本金仍按旧年档乘年数，不重新套未来档。

## 交互与验证

切换缴费时间后重新计算所有未来档次，比较基线保留原方案；修改信息保留选择、同次会话恢复结果和档次；切城市回MINIMUM，满60岁或已无可继续年度时不显示该选项。年龄、缴费记录改变导致不再适用时，表单回默认计划；直接调用计算接口传不适用SIXTY则报错。
