# 新疆、西藏本轮记录（2.19.0）

历史记录：西藏状态已由2.20.0更新为核对退休年月后的有条件三项参考，见[西藏增量记录](employee-tibet-progress.md)。下文为2.19.0当时交付状态，不作为最新计数。

截止2026-10-22；只处理单位职工。沿用相同表单、地区选择、结果与方案切换，不扩居民或灵活就业范围。

## 已交付与停止项

- 新疆自治区14项开放2025年历史参考。基础养老金按8448元工资合并口径推算，个人缴费5069—25344元、未来指数工资8448元。合并依据是财新报道，未取得2025年独立待遇通知及合并办法原件，不能称全部年度待遇参数已获官方核实。主结果显示这一限制，不冒充2026核定标准。
- 2025-09是本工具允许使用这组录入参数的最早截至月（官方页面9月公开），不称当地法定生效日、补缴期限或2025年1—8月适用标准。2026缴费范围已有官方资料，但本轮不把2025待遇推算与2026工资混为一套。
- 兵团12项未开放。旧办法独立规定了最低保证待遇，现行适用性、年度计发与工资合并口径尚未核齐，不能仅因缴费工资相同而继承自治区模型。
- 西藏7项未开放。2025年工资11777、范围7066.2—35331以及可用于待遇计发已核；普通待遇含按实际在藏工作时间计算的高原补贴，不能把所有缴费年限视为在藏工作，也不能把补贴默认算零。地方55/45等退休条件与2025年延迟退休衔接未核实，直接套全国年龄可能算错何时领取。
- 累计30省含334可算项、35未开放项：西藏7、兵团12、湖北15、菏泽1。不是全国全部可算。
