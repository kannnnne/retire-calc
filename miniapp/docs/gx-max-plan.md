# 广西居民补缴：先选月领金额（2.22.1）

2026-10-24，在2.21.1自动匹配草稿上增加多档预计算及可调方案，底层广西政策、其他省与职工／灵活范围不变。

## 用户操作

填写页、结果页、手填补缴页统一入口“补缴方案”。先预计算六组月领约数，参考年缴200／500／1000／2000／3000／6000；每组按当前输入走原计算引擎，不写死月额、不承诺任意想领多少都能实现。同样的十元取整月额可能对应不同档次，卡片小字标年缴参考用来区分。

选中一个结果，显示起领年月、补漏缴几年及费用、已缴提档差额、以后每年交多少和共交多少。默认“到60岁交够15年”，可切“现在补够15年”。15年是本广西普通规划所用最低累计年限，不提供任意增加第16年或强行所有人60岁补足的保证。

展开“自己调整怎么交”后，统一年档优先下拉，也可选“自己填写”：
- 输入其他现行合法档次可整体重配；旧年按不超过该数的原年合法最高档，已交高于该数的年份原样保留，不退费也不减本金。
- 以后年缴单独选择，与历史补缴金额互不覆盖。
- 每个补漏／已交年度可按原年合法档次单独选择；已交年度不能低于原金额，选择原金额就是不提档。选择即重算月领和费用。
- 重新点击金额卡片或统一换档会重配逐年调整；切补足方式清逐年调整，因为可用年份可能变化。
- 年档输入时不移除编辑控件；待更新或非法金额不能应用旧结果。修改后核对状态清空。

## 年份与资格

完整分年记录及原金额优先保留。只有年数时保留已知部分、其余按最近年份推定，明确是假设而非查询；不知道今年是否已缴时暂按已含，年缴额空白时暂按200，均提示。年份修改默认收起，只填年龄时从截至月份推定出生月。

先展示独立预览，不改变form/result。引擎临时确认仅用于计算假设费用，不能当成经办已审批。核对记录、可补范围及补贴并确认未领后才应用；取消或应用失败保留原结果，换地区清预览。未参保、已领、可用历史年不足、非法档次、未取消的其他核定方案等条件仍拦截，不虚构年份。

原年最高档1000／2000／6000分段复用；旧年补漏及提档无补贴，当前年度提档只给原已享补贴与新档补贴差额。原已享补贴优先沿用记录，未知时以原档标准作可改参考；查询余额模式不重复加入历史本金。

## 回归算例

既有用例：1967-11出生，2021及2023—2026五年各200，2022未交，原本金1000且未知历史补贴利息。

到60岁共15年：年档参考200／500／1000／2000／3000／6000，对应未来总自费2000／6500／14000／28000／37000／64000元，实际费用由各年档次组成。最高方案补9漏年并提5年，现在58000、2027再6000，月领约660，2027-12起参考。现在补够15年：最高补10漏年并提5年59000、没有额外第16年，月领约620；与原截图一致。年档2000方案：补漏17000、提差9000、以后2000，总28000。

同样输入可以因实际年份、原补贴、账户余额而变化，预计算不能替代核验。经办批准、到账、可补起点及待遇起领月份仍须当地确认，工具不把模型缴费月当作统一法定截止日。

## 2.22.1填写与导航核查

历史金额主字段可选当地现行档次或自己填写，不能把这份选单当历史各年的合法档表。原年档、平均数和月缴原样保留；仅未修改默认随地区取最低年档。旧会话缺pastAmountAuto按实际输入处理，不自动覆盖。重填时重新取所在地区最低档。

未来年缴自填用独立草稿，确认或计算时校验当地允许档次，不在键盘输入中途归一化为旧档；连续金额地区保留连续规则，待核地方仍用原annualInput确认流程。地区切换清未来手填草稿。

结果只留一个openSupplementPlans入口，符合已参保GX普通记录时直接开预计算，否则保留查记录／参保条件路线。按实际年份填写调用原openPaymentPlanner并关闭quickPlan，取消仍恢复原结果。人工操作步骤：选广西贵港，历史下拉选200，算后点补缴方案，选中档，再展开改年档，返回后改信息；手机显示未实际验证。
