# 广西最高档快捷方案（2.21.1）

2026-10-24，仅广西居民养老交互；复用2.20.1既有历史档次及补缴规则，不重新扩大地区或审批资格。

## 截图核对

用户当前方案补2012—2020及2022共10个漏年：2012—2013各1000、2014—2018各2000、2019—2020及2022各6000，合30000。已交2021及2023—2026五年，原各200，提到6000只补5×5800＝29000。本人现在合59000，已经15年，不再安排2027正常缴费；按当前自治区基础186、139计发和原账户估算，取整月领约620，2027-12开始为参考。截图没有算错；不与2.20.1保留2027年6000缴费、以新年替代较低上限旧年而月领约660的方案混淆。

这里只核对截图所述方案组成；补哪些年可办理、到账和起领月份仍由经办审核。原本金1000不再收取；历史补贴利息未知不假设全部已计入；如用查询余额则以余额为准不重复加旧年本金。

## 入口和操作

表单及结果页均有“最高档，一键配好”，手填补缴页增加“一键按最高档填好”。独立预览保持原白底蓝色样式，只突出起领月份、月领、现在补多少及以后怎样交，年份默认折叠。

- 到60岁交够15年（默认）：先安排当前规则下60岁前尚可正常缴费的年度，剩余缺年在可用范围内选最近的未缴年度；补各旧年最高档、将已有低档提高到原年最高档，以后当前最高档，15年即停。
- 现在补够15年：缺多少年先补多少真实漏年，已有年度同时按原年最高档提高，不安排额外第16年。
- 两种都只生成明确年份的补缴／提档记录，送回原gx-makeup引擎校验。旧年最高分段保持1000／2000／6000，不把6000倒套全部年份，不提高原账户、也不重复收取原金额。
- 完整分年记录直接读取；旧提档记录若覆盖全部已交年数且原金额与历史总额相符，也可读取。因此当前截图用户无须再输入5年的起止年和原200元。
- 只有累计5年却没有具体年份时，按最近年份自动匹配并立即显示参考金额，不再要求逐年点选。界面明确这是假设、不是查询记录；年份编辑默认收起。不知道今年是否缴费时暂按已含，原年缴额空白时暂按200元，均显示提示；实际已填年份及其原金额优先保留。已知原年缴200直接复用。部分已有记录的原金额不可被统一年缴输入覆盖，已填年份不能在这里悄悄删除。
- 不同年份原金额按已有明细分别保留，已经最高档的不再生成提档。查询余额模式沿用余额，不再加入历史缴费额。

当年提档原已享补贴优先用原提档记录中的值；无值时以原档补贴作明确参考，显示单个可改金额。例如200元原档参考35元，提高6000只再补165元。不是默认当年原补贴为0或重新给予全额200。当前截图若原手填已享补贴200，会保留该输入、不给差额；查到实际35可一次修改，不要求逐段重填。

金额预览单独保存，原form/result不变。预览引擎中的临时确认只用于计算假设费用，不保存到用户form、也不代表社保已审批。用户核对原记录、可补年份、补贴及尚未领养老金后，才一次性写入自动生成的明细并进入原统一结果页。取消仍是原输入和原结果；应用失败还原原form/result等；换省或县区清掉快捷预览，重填清掉草稿。

还没登记、已经领取、记录模糊、特殊核定补足方案未取消、漏年不够、历史档次不符等情况不强行拼出15年。普通历史欠费与有补贴的原制度过渡补足仍分开，不能认为所有人60岁都可按当前档买足15年。

## 键盘与状态

已交年份改为按钮，已有记录时不弹键盘。原年缴金额最多共用一个输入，键盘“完成”即可生成。修改当年已享补贴后，输入框不因预览失效而消失；点击完成或生成即可更新，不须手动收键盘再找另一个年份。每次换模式／年份／金额清核对状态，不沿用旧确认。

## 来源

沿用并重新打开核对[桂人社规〔2023〕2号三部门原文](https://guangxi.chinatax.gov.cn/zcwj/zxwj/202308/t20230828_391042.html)：未领且已参保可按规申请，原年度上限、历史无补贴、当年提档补贴差额、社保审核后推税务缴费。具体旧年档表及桂平起点继续使用2.20.1已核资料；没有新增“自动批准补缴”条款。

测试精确数：以已交本金1000估算、不含未知历史补贴利息，补59000且当年补贴差额165，月额186＋60165/139＝618.84，页面620；若原已享补贴填200则不给额外补贴，月额617.65，仍显示620。到60岁方案补58000、2027正常6000及200补贴、当年差额165，账户65365、月额656.25，页面660。不同输入导致的小额差异不改变截图620与660两种路线的解释。
