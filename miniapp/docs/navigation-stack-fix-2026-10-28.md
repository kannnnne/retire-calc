# 主菜单返回修复 2.26.2

## 问题与处理

实际在iPhone 5模拟器复现：居民菜单→养老金计算→底栏首页，首页仍显示返回箭头。根因是redirectTo只替换顶页，保留居民菜单父页。

主菜单统一通过root-navigation调用reLaunch；首页卡片、职工转灵活、普通计算页的其他计算也使用相同入口。当前主菜单若发现多层页面栈也会清理。居民菜单进入模块仍用navigateTo；基本/补缴互跳仍替换当前模块；政策和帮助保留详情返回。

输入及结果仍由原有onHide/onUnload写入应用内存，reLaunch不清理应用会话。

## 验证

- 1028项自动测试及build-dev.ps1的原生WXML/WXSS编译通过。
- 新增导航回归：四个根入口清栈、当前项清理旧栈、首页卡片及其他计算、详情返回、内存数据不清理。
- 实际模拟器：养老金计算结果→首页，首页无返回箭头。
- 实际模拟器：补缴/断缴→职工养老→灵活就业，主菜单无旧返回箭头。
- 实际模拟器：回居民菜单再进养老金计算，原1080元结果正常恢复。
- 实际模拟器：结果→缴费标准→原生返回，回原结果。

模拟器主页面左上角可能出现微信原生“首页”图标，和返回旧居民页的箭头不同。未手机实测、未上传、未送审或发布。
