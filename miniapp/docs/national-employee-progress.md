# 职工养老全国接入记录（2.18.0）

本轮截止：2026-10-22。只扩单位职工，复用现有表单、结果、方案切换和地区选择。居民仍369项，灵活就业仍原40城。

大陆31省369个选择项：29省含可算地区，共320项；未开放49项（2省全部暂缓，另湖北15项及山东菏泽暂缓）。可选择不等于已可算，不宣称全国已全开。

本轮只补河南、海南37项：河南18项用2024年人社政策解读的6606元待遇、2025年7月起缴费；海南19项仅开放2022年7599元旧待遇／2025年10月起缴费参考，近年待遇未核齐，不能承诺只差几十元。29省含可算地区不代表29省全市开放：湖北仅武汉与荆门，山东仍不含菏泽。原40城及其他工具不改。

此前重庆待遇沿用2024年8160元通知全文转载，缴费沿用2025年4404—22017元，未来指数分母为88065元/年÷12；人社公开答复确认1998年后平均指数上限3，历史超出要求核对，未来300%取整不允许指数超3。未采用仅见于裁判转载的2025年8240元。

武汉为2024年政府公开普通实际缴费案例中的8880元参考，不称该年最终年度标准；荆门采用荆门发布2025年5月23日披露的2024年6957元参考。两市缴费各按湖北2025年对应档，不把武汉计发额、缴费范围或案例套给全省。荆门官方报道30年指数0.8基础养老金1878.39元的示例独立校验通过。

此前接入山西、内蒙古、黑龙江、江苏、安徽、江西、山东（不含菏泽）、贵州、甘肃、青海122项。甘肃为2024年待遇／2025年缴费参考，其余2025年；转载、文件副本、官网搜索正文及推导记录保留。沈阳、大连、长春差异和吉林农垦排除继续保留。
