# 职工养老全国接入记录（2.16.0）

本轮截止：2026-10-22。只扩单位职工，复用现有表单、结果、方案切换和地区选择。居民仍369项，灵活就业仍原40城。

大陆31省369个选择项：可算25省280项，未开放89项（6省全部暂缓，另山东菏泽单独暂缓）。可选择不等于已可算，不宣称全国已全开。

本轮在原15省158项基础上新增山西、内蒙古、黑龙江、江苏、安徽、江西、山东（不含菏泽）、贵州、甘肃、青海，共122项。原40城参数不变。其他省份保留现有参考口径，不因本轮追溯升级。

新十省除甘肃外均采用2025年历史参考；甘肃为2024年待遇／2025年缴费参考，明确混合年份，不冒充2026年实际申报标准。山西、江西取得通知全文转载，山东为原通知PDF公开副本；江苏、内蒙古部分证据是官网搜索正文或官方计算实例。所有来源状态、推导过程保留，不把第三方托管写成原政府网站。

山东通知明确7831元不含菏泽，单独拦截并清除该地区金额参数，不以其余15市为代价停开全省。贵州按省统一全口径规则和年度工资通知推导，青海与黑龙江普通60%—300%缴费范围由工资换算；安徽、江苏未来指数工资按300%上限÷3近似。缴费工资、范围、待遇计发基数分开保存。

先前已接的沈阳、大连、长春差异保留；吉林年计发额÷12，缴费有效期至2026年6月，之后仅作历史参考，排除农垦企业。
