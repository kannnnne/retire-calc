# 灵活就业养老

独立分包 `flexible/pages/calc/calc`，首页与固定底栏入口。原职工路由保留，单位/居民原有模型不变；单位页面原缴费类型切换改为跳往独立工具。

## 输入与计算

- 默认40岁男性，单位10年、灵活2年、最低档月缴。历史年数和剩余月数分别填写，0表示未交过。月份不能重复计入，也不能把居民养老年限直接相加。
- 默认账户粗算：当前最低基数×8%×累计月份，未还原历年基数和利息。展开后可填写单位历史平均养老个人扣款、灵活历史平均全额养老缴费；前者全部入账，后者仅40%入账（20%缴费中有8%基数进个人账户）。2006年前参保不能套用此粗算，须填查询余额。
- 查询余额单独保留，允许填含利息总余额；计算时不再另加利息，避免重复。不要填累计社保/养老全部缴费金额。
- 初次缴费日期暂沿用22岁当年7月建议，更多设置可改；只用于时间跨度及历史权益校验，不据此生成额外缴费年限。实际月份超过跨度时阻断，并展开日期设置。
- 将两段月数合并后调用原 `utils/forecast.js`，未来固定为FLEXIBLE，个人自付20%，账户入账8%。可选最低档、自填月缴、自填基数，以及交至退休、最低档交够、自选时间。基数上下限按截至月份取已核验参数。
- 领取年龄及最低年限沿用已验证职工引擎，2030年后不能固定按15年算。到龄不够按后续逐月缴费推演，不提供普通断缴任意一次补齐；延缴资格/待遇领取地仍需社保确认，暂不支持截至月已晚于法定退休月的核算。
- 已交年数和账户不足以还原真实历史缴费指数，未知按0.6，未来利息/增长未计。月领UI取中点到十元，保持“约”，非承诺值。
- 计算结果、所选方案及展开态在本次应用会话恢复；编辑保留输入，重填恢复默认，三工具互不覆盖。
