# 灵活就业养老

独立分包 `flexible/pages/calc/calc`，首页与固定底栏入口。原职工路由保留，单位/居民原有模型不变；单位页面原缴费类型切换改为跳往独立工具。

## 输入与计算

- 默认40岁男性，单位10年、灵活2年、最低档月缴。历史年数和剩余月数分别填写，0表示未交过。月份不能重复计入，也不能把居民养老年限直接相加。
- 默认账户粗算：当前最低基数×8%×累计月份，未还原历年基数和利息。展开后可填写单位历史平均养老个人扣款、灵活历史平均全额养老缴费；前者全部入账，后者仅40%入账（20%缴费中有8%基数进个人账户）。2006年前参保不能套用此粗算，须填查询余额。
- 查询余额单独保留，允许填含利息总余额；计算时不再另加利息，避免重复。不要填累计社保/养老全部缴费金额。
- 初次缴费日期暂沿用22岁当年7月建议，更多设置可改；只用于时间跨度及历史权益校验，不据此生成额外缴费年限。实际月份超过跨度时阻断，并展开日期设置。
- 将两段月数合并后调用原 `utils/forecast.js`，未来固定为FLEXIBLE，个人自付20%，账户入账8%。可选最低档、自填月缴、自填基数，以及交至退休、最低档交够、自选时间。基数上下限按截至月份取已核验参数。
- 领取年龄及最低年限沿用已验证职工引擎，2030年后不能固定按15年算。到龄不够按后续逐月缴费推演，不提供普通断缴任意一次补齐；延缴资格/待遇领取地仍需社保确认，暂不支持截至月已晚于法定退休月的核算。
- 已交年数和账户不足以还原真实历史缴费指数，未知按0.6，未来利息/增长未计。月领UI取中点到十元，保持“约”，非承诺值。
- 计算结果、所选方案及展开态在本次应用会话恢复；编辑保留输入，重填恢复默认，三工具互不覆盖。

## 2.7.3 广东、广西女性退休类别

按退休时仍为灵活就业身份的普通情况处理；若届时转为单位职工，应改用职工入口并按实际岗位和社保认定的类别计算。本工具尚未自动判断未来身份转换，也不能通过合计几年单位缴费替代岗位审核。

- 广东21市：[2024企业养老经办规程全文](https://www.jiangmen.gov.cn/bmpd/jmsshbxjjglj/zwgk/zcjd/content/post_3170812.html)第三十二条区分曾以职工身份参加与一直灵活就业的女性。一直自己交、没有单位职工参保记录，原退休类别为55岁；有单位职工记录仍须结合实际岗位确认。表单在单位月数为0时去掉原50选项，变为原55；在有单位记录时保留原50／原55选择，不自动把所有人认定为原50。
- 广西14市：已取得[自治区人社厅桂人社发〔2021〕39号原文](http://rst.gxzf.gov.cn/zwgk/xxgkzcfg/fgfxlm/t10218731.shtml)，2021-09-15签发、2022-01-01起执行：灵活就业女性统一原55岁，单位／灵活身份转换的按申领时身份。替换原先桂林官网公开报道依据；退休时仍灵活就业，即使过去有单位年限也不能在本入口选原50，仍按国家新规定叠加渐进延迟。

原55岁是国家延迟退休表的人员类别；不是承诺固定55岁退休。仍按出生年月计算延迟后的法定退休年月。例如1985-06出生原55类别为2043-06，原50类别为2040-06。

`utils/flexible-category.js`负责选项及校验。灵活页计算传入`pastEmployeeMonths=historySummary.unit`；引擎对广东FLEXIBLE原50要求正整数且不超过paidMonths，对广西FLEXIBLE原50直接报错。单位入口的EMPLOYEE不受此灵活规则限制，外省不自动沿用两广规定。男性不变；不增加身份勾选项。错误或旧会话原50不适用时改原55、清结果并提示重算，不保留旧起领时间。增加单位记录后可再次选适用类别；原55有效结果正常恢复。

35市职工和灵活政策资料均加入对应省级来源，广州旧公式及深圳独立公式也有来源；居民入口不混入该规则。深圳非深户实缴10年等原范围校验不变。702项自动测试及2026-10-19 12:31:08原生编译通过；未GUI／手机测试、未上传。
