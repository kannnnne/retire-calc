# 广东、广西省级参考覆盖

2026-10-17，版本2.3.0。用户明确允许先按省级最低标准覆盖全部城市、标明口径，再逐市补齐。不是已经核实35市所有本地政策。

## 参数和边界

- 广东普通职工（深圳另列）：2026年7月范围5521—27603元；2025年待遇基数9493。普通基础养老金保留低于0.6的指数修正。新城市未来指数分母暂按9493不变，是静态估算假设，不还原历年指数。
- 深圳：2025待遇基数11293，2026缴费范围同广东；未来指数采用广东9493参考。仅非深户、无地方补充养老权益，需显式勾选；深户21%、地方补助、历史特殊待遇及省市待遇就高核定尚未实现，不得说全部深圳参保人已支持。
- 广西职工：2026年度范围4204.8—21024；2025待遇基数6983，未来指数分母暂按6983不变。个人8%、灵活20%、账户8%，普通全国公式；按桂人社规2019年26号的指数和年限取位，界面仍是约数。
- 广东居民：除广州使用原本地模型，其余20市使用2025省级基础养老金最低240元；省级九档180/240/360/600/900/1200/1800/3600/4800，最低补贴30/30/30/60/60/60/60/60/60。各市县可能有不同档次和更高补贴，因此称“省级参考档”，不称已核定的当地可办理档。普通按年交，不足延缴到65岁后按同档参考补年限，无补缴补贴；办理资格和补缴档须核定。不能凭当前年龄推断历史过渡待遇。
- 广西居民：2025基础养老金最低186元，65岁以上增加5元；超过15年每多1年加2元。15档200至6000，对应35至200元补贴。仅普通逐年交满15年，不将现今临近60岁直接视为制度建立时临近领取年龄，故不默认60岁补足。区县额外待遇、特殊历史补缴和提档不计。
- 广东/广西居民省级参考的个人账户按国家文件的139计发系数静态计算；广州独立模型按年龄表，不把广州表静默移到省级模型。历史未知账户只估本人缴费，不虚构过去补贴及利息；查询余额与历史缴费不重复相加。
- 年度缴费截止、补缴档次和实际起领月份由当年当地通知及核定确定，页面不编造未来固定截止日。
