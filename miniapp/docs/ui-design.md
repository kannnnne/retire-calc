# 界面约定

2026-10-15 用户选择白底蓝色、常规工具风格。面向普通参保人，优先可读、好点、少填。

## 页面结构

- 首页提供两个工具入口和帮助，不用营销大标题或多层装饰卡片。
- 底栏固定为首页、职工养老、居民养老，点当前页不重新加载。帮助放页面右上角及首页。
- 两工具均在同一页填写，计算按钮固定在底栏上方；内容预留滚动及安全区。
- 职工按基本信息、已有账户、后续计划分组；居民保留年数和年缴默认估算。
- 预算、历史明细、账户利息、截至月份等次要设置折叠。资格和余额等事实不能代用户填。

## 样式

全局以app.wxss为准：主色#2463eb、正文#172b4d、次要文字#576579、白色表面、#f5f7fa页面底色。使用系统中文字体；输入、分段按钮最低88rpx，计算按钮96rpx。不使用小字号浅灰提示、渐变或玻璃拟态。按钮角色：蓝色实心主操作，浅色次操作，文字帮助/展开。

UI UX Pro Max的minimalism-and-swiss-style检索用于简洁、高对比方向；初次返回的玻璃拟态、手写字体和营销页模式不适合本工具，未采用。WXML/WXSS原生实现，不套React、Tailwind或GSAP。

## 验收

必须实际检查首页、两个示例直接计算、返回修改、底栏切换、帮助、展开设置和滚动到底后按钮遮挡。自动测试与模拟器检查不能代替真实手机、大字号和横屏验收。服务端口用户暂不开启，不调用CLI上传；上传与发布状态见release.md。

### 2.0.4 居民结果精简
默认一张账单：每月领/起领年份、已交年数和本人历史金额、还差年数、按年缴费、到时一次补缴、后续总额及回收后续支出年数。对比和详情默认折叠。未知本人已交总额时明确未知，不把含补贴利息的账户储存额冒充已交额。表单与计算规则不变。

### 2.0.5 职工页说明入口
职工页移除右上角帮助与底部横排“依据与假设/隐私说明/失业后怎么交”，统一由首页“使用说明与隐私”访问；帮助页补入失业后续缴入口。保留结果的计算假设折叠说明。

### 2.0.6 居民表单默认值
移除居民页页头帮助，说明统一从首页访问。首次进入默认55岁、交过5年、历史年缴360元、今年已缴且计入年数、以后年缴360元、参保条件勾选；历史余额和补贴额度不伪造，仍按历史缴费估算。显示一行默认值提醒。已填写的会话数据仍优先恢复，不覆盖用户修改。

### 2.0.7 居民结果数字卡片
首屏仅保留领取年龄/年份、每月约领整数范围、后续总费用，以及相加的两个费用格（年缴金额×年数、到龄一次补缴金额）。已交、差年限、回本、档次表和公式全部收入同一个详情入口。保留原精确计算值，仅展示金额取整；会话恢复时重新派生显示字段，避免旧缓存结果空白。无年缴/无补缴/已满15年的分支只展示必要内容。

### 2.0.8 结果后调整未来缴费
三块独立手风琴卡片：蓝色“想多领？调整以后怎么交”、灰色“过去交低了，还能补差吗？”、“原始信息与计算详情”。展开按钮含独立圆形＋/−，展开内容留白、分组线和明确标题。计划选择是可点选卡片，固定历史金额，标注未来年度/未来年缴、增量支出和月领差；个人档与自费集体档分开，后者须用户确认无村集体补助。补缴只作同个人档假设，明确需核定，不承诺自由追加十几万或历史提档。

### 2.0.9 单数月领与金额选档
月领用精确上下限中点四舍五入到十元，主标签“退休后，每月领”，无区间及“约”；仅展示取整，原模型和支出金额保留。七档为两列金额选择按钮，仅月领及选择状态，选择后上方账单更新并滚回顶部。自费集体档默认0，置于“其他增额方式（选填）”内，确认无村集体补助后才允许加交，禁止为追求高金额默认勾选。
表单仅对模型实际涉及的人员显示核对项：1967-08及以前、已缴不足15年且非从未参保者的历史过渡；65岁及以上不足15年的延缴确认。普通55岁默认不显示，不能为简化默认为已核对。默认值与会话输入策略不变。Skill检索的适用建议是以静态标签和真实可选动作区分语义，布局取舍依据用户反馈及原生模拟器实测。

### 2.0.10 自然文案和文件阅读
保留计算页布局，金额标签恢复“约”。产品用语改为“怎么算的”“政策文件”“还要交多少、以后领多少”，不把“依据”“情景”“核验”“宣称”等内部表述直接呈现给普通用户。事实条件及不确定金额说明保留。居民政策链接进入本地文件要点页，标题/发布单位/日期/相关条款可读，官网原文另有明确复制按钮和浏览器指引；不伪装成已打开官网全文。

### 2.0.11 职工页
同页展示参保情况、账户、以后怎么交；默认40岁/22岁年7月开始/连续/账户粗算/单位在职/最低档/交到退休。日期选择有界，自动建议可改且不覆盖手工日期。账户明确“不知道帮我估”和“查过直接填”，三个估算依据与查询值隔离。粗算条件可见，不能把当前最低档乘历史月份称为实际历年最低档余额。未来缴费用具体说法，结果与居民页相同白蓝金额卡、单个月领约数、支出/年数卡、点击交法回顶部更新，细节收起。保留性别类别和在职缴费义务提示。

### 2.0.12 默认摘要、点修改展开
用户指定的账户/以后每月缴费块在职工页。默认单行标签、金额和修改入口，下方最多一行必要说明；计算公式、账户方式、未来身份/缴费基数选择收进各自编辑区。不用大段提示和多层颜色框。隐藏必填错误会自动展开相应区。交到什么时候为普通同行picker。账户摘要对粗估加约字，查询值保留小数；每月缴费保留实际小数，不把最低档与当前工资交法混淆。

### 2.0.14 计算与返回修改

职工、居民提交按钮统一为“开始计算”。居民结果底部固定“修改信息”（蓝色主按钮）与“重新填写”（次按钮），替代正文中容易忽略的修改入口。修改保留原资料，重新填写恢复55岁/5年/360元等默认值，清除额外交费及历史分段。填写页提供“恢复默认”。同一次使用中重新进入居民页保留输入、回到填写页，不恢复结果或展开状态；提示“已保留上次填写，可直接修改”。仅内存缓存，完全关闭后重新打开仍用默认值。

### 2.0.15 职工结果修改入口

职工结果页“修改信息”使用与计算按钮同位置的固定蓝色主按钮；表单和结果均预留底部空间，保证最后一项内容可滚到按钮上方。点击仍调用原edit，保留输入，回顶部填写，不增加新信息区或说明文案。

### 2.0.16 统一表单细节

两工具结果页共用全局result-actions双按钮（重新填写/修改信息），职工reset完整恢复默认并重算派生金额。全站原生picker统一使用CSS线条箭头，不再依赖字体下拉字符；保留原生选择面板。居民年龄与出生月在同一行切换，不再显示独立填写方式行，切换保留两种输入。职工出生/退休类别并排，下方按已交/未来缴费分组；移除行底线和计划框重复边线。账户摘要列明每月账户入账额×累计月数，当前最低档粗算提醒继续可见；未来月缴旁显示有效基数，最低档方案不沿用自填工资。政策模型与计算精度不变。

### 2.0.17 主界面文案与首页页底

首页仅保留品牌和一句“为往后的日子，算一笔账。”，删除免费/登录/本地计算宣传项。使用说明与隐私以弹性布局推到页底，位于底栏之上；小屏内容多时仍顺序向下滚动，不覆盖入口，中间留白。居民入口副标题改为农村居民/城镇居民，和职工入口身份描述一致。

职工、居民填写页删除默认值提醒、默认毕业日期旁白及底部免费隐私宣传语；职工去掉功能复述副标题，居民去掉重复地区标准说明。保留当前最低档估算并非历史实缴、特殊补缴核对、资格及输入错误；结果底部仅留一句金额参考说明。说明/隐私页面继续保留数据处理和政策信息。未新增广告或占位卡。

### 2.0.18 以职工养老统一两类工具

两工具使用app.wxss中的共享表单行、分组标题、月领卡、费用格、结果折叠栏及参考说明，居民保留年龄/出生月、年缴和到龄补缴等业务差异。结果均先展示月领，再展示接下来这样交、以后共交；居民年缴计划、补缴年数/同档暂算和年份仍保留。折叠统一“换个交法看看”“缴费记录与计算详情”，居民另有“补缴与提档说明”。

按用户最新选择，居民onLoad恢复本次会话的计算结果、所选未来档、原始比较基线及折叠状态，与职工一致，覆盖2.0.14回填写页的旧约定。修改信息保留表单并清除结果；修改后未重算就离开，回来仍为填写页；重新填写恢复默认并清结果。只保存在当前小程序运行内存，完全关闭后不保证保留。不把旧结果重算成新方案，恢复时仅重建金额显示和可选方案展示。
