# 两广35市目标与进度

目标模式已于2026-10-18启动，状态：进行中。基线是已推送的2.5.0（b4aacca），624项自动测试及本地WXML/WXSS编译通过。当前尚未达到“35市本地规则全部核齐”，不得把已有READY或者省级参考当作完成。

## 执行顺序

1. 为每市核对本地基础待遇、档次和补贴、普通领取及补缴条件、年度缴费时间、具体行政范围；记录原文链接、文号、有效期和取用字段。
2. 优先处理深圳、珠海、佛山、东莞、中山等与省级参考差异明显的城市，再逐市复核粤东西北和广西各市；县区不同则增加必要的地区分支，不把市区金额套给全市。
3. 复核职工／灵活就业省统筹参数及地方例外，明确哪些情况可算、需补信息、应阻断。居民方案区分正常年缴、断缴补缴、到龄补足、历史提档，不能互相替代。
4. 将已核字段接入代码；查不到现行原件的继续追查官方公报、公开目录及经办答复，保留具体缺项，不能拼凑邻市标准、旧年度或人均实发金额。
5. 按每市和政策边界编写自动案例，执行三入口回归、页面事件测试与build-dev.ps1；同步两工作副本、commit并push。GUI、模拟器、手机和上传由用户完成，不报告为代测完成。

## 完成标准

- 35市都有逐字段核对记录、可追溯来源与当前实现状态；同省统一规则有适用于该市的依据。
- 已生成的方案在所声明普通范围内适用。缺少资格、区域或关键参数时，明确补信息／阻断或只给清晰标注的最低参考，不能冒充本地完整待遇。
- 关键待核金额和资格未解决时，不能把全量目标标为完成。确属无法公开核实的，列明尝试、缺少的文件及应向经办核对的问题。
- 自动测试和编译通过、Git推送成功；人工验收步骤列出，未上传不称上线。
