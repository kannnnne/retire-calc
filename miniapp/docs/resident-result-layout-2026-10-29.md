# 居民结果布局 2.33.0

用户需要先判断领多少、什么时候领，再判断投入多少、多久领回；原版把回本放在收入卡、费用留在下一卡，需要反复对照。

本次仅重排结果，不加菜单、选项或政策规则。统一顺序：
1. 每月约领（最大字号）。
2. 起领年龄/时间，参考方案保留参考标记。
3. 还需交（从现在起）。
4. 前后总共交（历史费用＋还需交）。
5. 全部/后续缴费回本，点整行查看计算过程。

以上同卡；下方“这样交/接下来这样交”仅列正常年缴、补缴和年份，不再重复总额。历史金额未知时，第4项称“本次合计”，小字注明“未含以前缴费”；第5项为“后续缴费回本”。不能把未知历史说成零元，也不因此强迫用户补填。

基础、普通、广西快捷及模糊参考复用 resident/templates/cost-summary.wxml；未采用并排多宫格，窄屏金额与标签使用左右行排、金额禁止挤缩，说明不默认展开。UI技能检索两次未找到贴合此结果摘要的建议，本次依用户截图与现有样式做保守调整，未把不相关检索结果写成设计依据。

验证：广州55岁、4800元档，仍月领1080、起领2036、费用72000、回本67个月。历史1000、后续64000时分别显示64000/65000；历史未知只计64000并明确标签。三项新回归验证数值对应、未知历史及所有模板统一引用；旧测试更新至新摘要位置，不删原费用未被改写的断言。1084项自动测试与 scripts/build-dev.ps1 原生WXML/WXSS编译通过。未GUI/手机实测，未上传。
