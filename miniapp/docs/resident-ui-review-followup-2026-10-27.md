# 居民养老界面续查（2026-10-27，2.25.2）

## 本轮实际使用

沿用用户授权，在微信开发者工具iPhone 5（320×568）模拟器输入：南宁、60岁、已交15年、每年200元、今年已含在年数中、尚未领取。实际点击计算、滚动结果、切职工再回居民、修改信息及重新填写。此次没有手机操作，也未上传。

## 用户感受及处理

1. 已交满且以后共交0元，主卡却写“只往后每年交的结果／只逐年交费”，与下面“已交够”冲突。现在仅在金额和年数均无需再交时显示“已交够”，删除该情况多余的逐年交费标题。仍需续交的结果保持原意；未改金额、资格或领取时间算法。
2. 小屏结果底部重新填写占得更宽，修改信息反而显小。原生按钮默认宽度覆盖了设计意图。共用样式明确重新填写宽度，让蓝色修改信息占主要空间；三种养老入口复用。只实际复查了居民结果的小屏显示，未将其他两种入口的结果宣称为GUI验收。
3. 切到职工再返回居民：原60岁／15年的计算结果及金额保留，页面回到结果顶部，不会强制重填。
4. 修改信息：回填60岁和南宁；重新填写：恢复默认55岁，地区仍为广西南宁。初始渲染有短暂的默认地区过渡，待渲染完成地区正确，不把过渡截图当最终丢失。

## 修复后复查与验证

同组数据重新实际输入后，主卡显示“已交够 · 60岁起领 · 2026-11”，每月约210元；明细显示已交15年、以后共交0元。此为现有省级参考参数下的界面输出，不是个人待遇认定。两个结果按钮主次正确。修改、重填均已实际点击。

新增自动用例核对已够／未够的显示状态及重填保留地区。1010项自动测试及原生WXML/WXSS编译通过。上一轮6组追加事件案例及GUI范围见[前轮记录](resident-ui-review-2026-10-27.md)。

本轮只修上述两项，不扩大政策研究或重做布局。手机软键盘、真实触控和真实老人阅读仍需用户手机验收。
