# 居民养老模块拆分计划（2026-10-28）

1. 居民入口只做选择：养老金计算（没交过）／补缴断缴（交过、没交满）。
2. 养老金页主体输入卡内选择地区、年龄或出生年月、年缴档；默认当地已核最高可选档。例外：未核本地年额不能虚构最高档；成都保留城乡身份，市县差异保留必要选择。
3. 普通计算不带历史补缴，结果只显示月领、起领、正常年缴及到龄补足的现有规则参考。补缴资格不因60岁自动成立。可携地区、年龄和档次进入独立补缴页。
4. 补缴页先填已有年数和以前金额；记不清、分年记录、账户等收进选填。复用既有引擎和方案，保留资格核对，提供返回养老金计算的快捷入口。个人数据仅内存传递，不在URL传输。
5. 本地政策单独页：地区、已核档次／补贴表、基础额及参数年份、规则适用范围与原文。表内不把缴费档对应通用月养老金，待遇必须结合个人资料另算。
6. 检查入口、带数、改地区最高档、返回恢复、错误提示、特殊地区、历史规则不回归；自动测试、原生编译、模拟演练反馈修复后交付。真实手机验收和上传未执行不得报告完成。

设计沿用白底蓝色、大字和主按钮；主流程少量输入，政策及专业说明按需查看，不增加宣传横幅。
