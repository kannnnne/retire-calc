# 退休算盘 微信小程序

免费离线养老计算工具，原生WXML/WXSS/JavaScript，无服务器、域名、云开发、登录、支付或输入磁盘保存。用户确认1.1.0已上线；最新本地2.4.0已测试编译，未上传。上一开发体验版2.3.0于2026-10-17 22:45上传成功。用户负责开发者工具、手机验收及上传，详见docs/extended-coverage.md。正式名称“退休算盘”由utils/brand.js集中配置，运行scripts/sync-brand.js同步导航标题。

## 运行

微信开发者工具导入D:\project\retire-calc-mini，AppID wx1e58d0b9d6cdf939，启动页pages/home/home。无需npm安装或构建，npm test执行613项检查。随包decimal.js 10.6.0（MIT）。

## 地区扩展（2.4.0）

广东21市、广西14市均已接入三入口。广州保留原模型，其余居民城市为明确标注的省级最低标准参考，不包含未核实的市县加发，不能宣传已算出各市完整待遇。深圳职工/灵活仅支持非深户且无地方补充养老权益的普通情况，必须显式确认；深户21%与地方补助尚未开放。北京、上海继续支持现有普通情景。成都、杭州、西安三个入口已开放注明范围的本地或省级参考：杭州采用2026官方职工参数；四川职工保留2024历史参数；陕西计发年度原件待补，使用注明来源的披露参考。居民杭州/西安用省级最低参考，成都用独立比例与入账模型。详见[新增三城范围](docs/extended-coverage.md)。

职工采用2026缴费范围与注明年份的待遇参数，未来工资、利息、政策调整未计入；广东/广西新接入城市未来缴费指数分母暂按所用2025计发参考参数不变，属于静态估算假设，不能视为个人历史核定指数。居民广东按普通延缴至65岁后补足参考，广西只算普通逐年满15年，不默认推断历史补缴资格。范围、来源、限制见[省市覆盖](docs/province-coverage.md)和[多城市核对表](docs/multi-city.md)。

## 功能

- 主页三个养老入口，固定首页/职工养老/灵活就业/居民养老；运行内存保存各工具独立输入。
- 广州职工养老单页填写、日期/缴费简化、单位8%及灵活20%本人费用、四方案、领取时间与回收对比；旧分享路径保留。
- 广州灵活就业独立入口：单位与自己缴费分段累计，个人账户估算/查询余额、按月自选金额及后续费用，详见docs/flexible-pension.md。
- 广州居民普通参考情景：年龄或出生年月、已缴年限、余额/历史估算、年缴/历史月缴及分段、七档与一次预算、延缴及65岁参考一次性缴费、后续费用和待遇/回收对比。
- 居民结果固定既往缴费，可调整未来个人年档；无村集体补助时支持未来自费集体档对比。历史差额提档原期限已结束，不生成任意补十几万方案；65岁补缴档次仍需经办核定。
- 广东21市、广西14市可选择并按明确范围参考计算；北京、上海普通模型已接入，成都/杭州/西安已有注明范围的参考；预留区县注册和新工具入口。
- 脱敏查询图解、政策链接及隐私说明，分享不携带输入。

## 模型边界

广州原模型参数源utils/policy.json，修改后npm run sync-policy；地区扩展参数见utils/city-policies.js、utils/province-policies.js及utils/extended-policies.js。广州原模型2026缴费范围已录入，计发基数仍2025年9493元参考，未知指数0.6、未来增长/利息0。

居民数据独立resident/data/regions.js；基础待遇采用官方2025工作总结中的297元/月，显示参考年份，不宣称2026最新值。资格、补贴和年缴时间假设、历史估算与未支持范围见docs/v2-implementation.md。未知历史补贴不凭空补发，2012年历史过渡及65岁补缴须先核对；具体截止日不捏造。

旧Java仓库https://github.com/kannnnne/retire-calc独立，未同步本轮居民工具及全部新参数。本地改动不等于线上更新。各包源码小于2MB，实际打包以开发工具为准。

## Git 提交

小程序的 Git 副本位于原仓库 miniapp/，旧 Java 网页版保留在根目录。当前开发工具仍使用 D:/project/retire-calc-mini；每次改完验证并上传开发版后，运行 scripts/sync-git.ps1 同步到 D:/project/retire-calc/miniapp，再检查差异并提交、推送。不提交 output、target、私有配置和后台快照。若删除源文件，需检查 Git 副本的对应旧文件。
