# 退休算盘 微信小程序

免费离线养老计算工具，原生WXML/WXSS/JavaScript，无服务器、域名、云开发、登录、支付或输入磁盘保存。用户确认1.1.0已上线；2.0.18已于2026-10-17 10:14上传开发版，未送审或正式发布。正式名称“退休算盘”由utils/brand.js集中配置，运行scripts/sync-brand.js同步导航标题。

## 运行

微信开发者工具导入D:\project\retire-calc-mini，AppID wx1e58d0b9d6cdf939，启动页pages/home/home。无需npm安装或构建，npm test执行491项检查。随包decimal.js 10.6.0（MIT）。

## 功能

- 主页两个养老入口，固定首页/职工养老/居民养老；运行内存保存各工具独立输入。
- 广州职工养老单页填写、日期/缴费简化、单位8%及灵活20%本人费用、四方案、领取时间与回收对比；旧分享路径保留。
- 广州居民普通参考情景：年龄或出生年月、已缴年限、余额/历史估算、年缴/历史月缴及分段、七档与一次预算、延缴及65岁参考一次性缴费、后续费用和待遇/回收对比。
- 居民结果固定既往缴费，可调整未来个人年档；无村集体补助时支持未来自费集体档对比。历史差额提档原期限已结束，不生成任意补十几万方案；65岁补缴档次仍需经办核定。
- 广东21市、广西14市可选择，其余城市尚未开放；预留区县注册和新工具入口。
- 脱敏查询图解、政策链接及隐私说明，分享不携带输入。

## 模型边界

## Git 提交

小程序的 Git 副本位于原仓库 miniapp/，旧 Java 网页版保留在根目录。当前开发工具仍使用 D:/project/retire-calc-mini；每次改完验证并上传开发版后，运行 scripts/sync-git.ps1 同步到 D:/project/retire-calc/miniapp，再检查差异并提交、推送。不提交 output、target、私有配置和后台快照。若删除源文件，需检查 Git 副本的对应旧文件。
